# Image Drop Folder

Put your custom images inside `frontend/public/images/` using these exact filenames.
The app now uses direct public image paths like `src: "/images/..."` in the components.

- `branding/logo.png`
- `landing/agriculture-growth.jpg`
- `landing/water-soil.jpg`
- `landing/inclusive-development.jpg`
- `landing/full-width-banner.jpg`
- `landing/smart-slogan.jpg`
- `profile/user-profile-visual.jpg`
- `admin/admin-monitoring.jpg`

The app already points to these paths. Replace them with your own files and refresh the browser.
